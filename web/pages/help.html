HELP ="panel-header-sub">how it works
1

Add URLs — paste video links into the Library queue.

2

Pick a mode — audio-only, formats, and thumbnails live in Settings.

3

Run it — press Run on the Logs page and watch the output live.

⚡

This UI edits the same config.json the CLI uses, and the Run button simply launches download -e. Everything stays in sync, whichever interface you use.

CLI FLAGS same config, terminal flavor
video URL to the queue video URL from the queue-only export format (mp4, mkv, …) format (mp3, flac, …) download destination download queue
-a <url>add a
-r <url>remove a
-Atoggle audio
-f <fmt>set video
-F <fmt>set audio
-d <path>set the
-eexecute the
🖥

Serve this UI with cargo run --bin serve from the project root, then open http://127.0.0.1:3000.
